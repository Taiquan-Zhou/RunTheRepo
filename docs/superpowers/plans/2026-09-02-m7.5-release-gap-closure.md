Every task report appended to `docs/dev/pilot-evidence/m7.5-release-gap-closure.md` contains:

```text

```

For a production correction whose literal value or exact normalization cannot be known before diagnosis:

1. Commit the diagnostic evidence first.
2. Stop before RED or production edits.
3. Create the named narrow subplan from the evidence with the literal value/rule, exact tests, and exact changed files.
4. Obtain Owner approval of that subplan.
5. Dispatch a fresh implementer, then a different reviewer.
6. Controller verifies the diff and full gates.
7. Run the cumulative incremental canary on that reviewed HEAD.

This protocol is a required evidence gate, not an implementation placeholder.

### Same-HEAD Canary Rule

After each accepted production correction, run the repository directly affected by that correction plus every former failure already recovered in the current loop. Run them serially on the new reviewed HEAD. A former failure counts in `recovery_count(HEAD)` only when that one HEAD produces process success, a non-empty deterministic required Journey set with every Journey passing, a completed report, exact SHA, exact stop reason, cleanup PASS, and exact empty inventory. Do not add successes from prior HEADs.

If `recovery_count(HEAD) >= 4`, stop all remaining compatibility work and jump to Task 9. Otherwise continue in the order RG1, RG4, RG5, RG6, then RG2 diagnosis, then optional RG3 diagnosis.

The runner's policy construction is exactly:

```python
from __future__ import annotations

import argparse
from pathlib import Path

from typer.testing import CliRunner

from repotrial.cli import create_app
from repotrial.sandbox.base import SandboxProvider
from repotrial.sandbox.docker_sbx import DockerSbxPolicy, DockerSbxProvider


def main() -> int:
    parser = argparse.ArgumentParser()
    parser.add_argument("repo_id")
    parser.add_argument("url")
    parser.add_argument("commit_sha")
    parser.add_argument("compose_path")
    parser.add_argument("port", type=int)
    parser.add_argument("disk_mb", type=int, choices=(4096, 8192))
    parser.add_argument("model_endpoint")
    args = parser.parse_args()
    policy = DockerSbxPolicy(
        cpus=1, memory_mb=1024, pids_limit=64,
        disk_mb=args.disk_mb, total_duration_s=900,
    )

    def provider_factory(selected: str) -> SandboxProvider:
        if selected != "docker-sbx":
            raise ValueError("unexpected provider")
        return DockerSbxProvider(policy)

    app = create_app(artifacts_root=Path("artifacts"), provider_factory=provider_factory)
    result = CliRunner().invoke(
        app,
        ["inspect", args.url, "--provider", "docker-sbx", "--commit-sha", args.commit_sha,
         "--container-port", str(args.port), "--compose-path", args.compose_path,
         "--model-endpoint", args.model_endpoint, "--model-name", "deepseek-v4-flash"],
        catch_exceptions=False,
    )
    print(result.output, end="")
    return result.exit_code


if __name__ == "__main__":
    raise SystemExit(main())
```
