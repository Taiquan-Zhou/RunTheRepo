- [ ] **Step 1: Admit and run Linkding exactly once**

Run:

```bash
cd /home/repotrial/src/RepoTrial-m7.5-release-gap
test -z "$(git status --porcelain=v1)"
test -n "${REPOTRIAL_MODEL_API_KEY:-}"
sbx list
export REPOTRIAL_MODEL_ENDPOINT=https://api.deepseek.com
LINKDING_LOG="$(mktemp /tmp/repotrial-linkding.XXXXXX)"
set +e
/home/repotrial/.local/share/repotrial-uv/bin/uv run repotrial inspect \
  https://github.com/sissbruecker/linkding \
  --provider docker-sbx \
  --commit-sha 65813a75404b1319aca8b09700fadc0b15adabaf \
  --container-port 9090 \
  --compose-path docker-compose.yml \
  --model-endpoint "$REPOTRIAL_MODEL_ENDPOINT" \
  --model-name deepseek-v4-flash 2>&1 | tee "$LINKDING_LOG"
LINKDING_EXIT=${PIPESTATUS[0]}
set -e
LINKDING_RUN_ID="$(sed -n 's/^run_id=//p' "$LINKDING_LOG")"
test "$(printf '%s\n' "$LINKDING_RUN_ID" | wc -l)" -eq 1
printf '%s\n' "$LINKDING_RUN_ID" | grep -Eq \
  '^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$'
rm -f -- "$LINKDING_LOG"
printf 'linkding_exit=%s\n' "$LINKDING_EXIT"
sbx list
```

Expected: the command retains and prints a new `run_id` and `artifact_path`.
Any PASS, FAIL, UNSUPPORTED, or exception is preserved. The post-run inventory
must be exactly empty. Do not rerun Linkding in this plan.
